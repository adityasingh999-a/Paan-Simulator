# Paan Simulator

A Unity project for a paan shop simulation game.

## Requirements

- Unity `6000.0.78f1`

## Open the project

1. Clone this repository.
2. In Unity Hub, choose **Add** and select the cloned project folder.
3. Open it with Unity `6000.0.78f1`.

The project assets and settings are in `Assets/`, `Packages/`, and `ProjectSettings/`.
